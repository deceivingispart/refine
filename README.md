# Refine - Minimal Tweaks for Discord

A collection of snippets to enhance the Discord experience, making it more cleaner.

This "theme" uses **snippets taken from Vencord server**, some of which have been modified by me to fit a cleaner look.

```css
@import url(https://deceivingispart.github.io/refine/main.css);
```
If you are the original creator of any snippet used here and want proper credit, or if you prefer this snippet to be removed, contact me on Discord (glorificado).
